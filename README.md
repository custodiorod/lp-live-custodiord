# LP Live Custódio

Landing page de captura para o aulão gratuito de Claude Code do Rodrigo Custódio.

## Stack

- Astro + React + TypeScript
- Tailwind CSS
- shadcn/ui
- Google Tag Manager (`GTM-P5R6QPTC`)
- Imagens responsivas em AVIF/WebP

## Desenvolvimento

```sh
npm ci
npm run dev
```

## Validação

```sh
npm run typecheck
npm run lint
npm run build
```

A saída estática de produção é gerada em `dist/`.
